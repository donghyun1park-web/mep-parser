# 층 추가

**빌드 스크립트를 손으로 쓰지 말 것.** `stack.json` 에 레벨을 추가하고 `stack_build.py`
를 돌린다. stack 설정으로 표현이 안 되는 게 있으면 그건 버그로 보고할 일이지
우회할 일이 아니다.

## 절차

1. `stack.json` 을 찾는다. 없으면 만든다(형식은 `stack_build.py` 독스트링).
2. 새 도면을 `--scan` 으로 훑고 레이어를 확인한다. 미매핑이 많으면 **`map-layers` 로 먼저 간다.**
3. `stack.json` 에 레벨을 추가한다.
   ```json
   {"id": "RF", "z": 14750, "source": "옥상.dxf", "layer_map": "rf.csv",
    "align": "2F", "height": 4200}
   ```
4. **`--dry-run` 을 먼저 돌리고 멈춘다.**
   ```
   python stack_build.py stack.json --dry-run
   ```
5. **offset·2위 점수·증거를 사용자에게 보이고 확인을 받는다.** 여기가 강제 중단지점이다.
   `StackError` 가 나면 우회하지 말고 사유를 그대로 전한다 — 가드가 일하고 있는 것이다.
   증거 부족이면 `"offset": [dx, dy]` 로 직접 지정하는 게 정답이고, 그때도 값의 근거를 물어본다.
6. 조립 → 검증 → 빌드.
   ```
   python stack_build.py stack.json -o merged.json
   python verify.py merged.json
   ```
   검사를 통과한 뒤에만 FreeCAD 빌드로 넘어간다. 실패하면 `verify-model` 로 간다.

## 매번 다시 설명하지 않아도 되도록 못박은 것

- **보/거더 레이어의 선은 외곽선이다.** 중심선+가정폭으로 때우지 말고 페어링으로 실측한다
  (`opts: pair_max=…`). 축선이 DIMENSION 으로 그려져 있으면 `from=dim`, 단면은 `schedule=`.
- **콘크리트 보는 상단 = 슬래브 상단**, 춤은 슬래브 두께를 포함한다.
  **철골 거더는 반대로 상단 = 데크 하단.** (z 규약표는 `CLAUDE.md`.)
- **지지 구조 없이 떠 있는 층 금지.** 아래층 벽·기둥 상단과 이 층 바닥 사이에 공백이
  생기면 V004 가 잡는다. 잡히면 층고를 고친다.
- **개별 레코드의 `z_base` 를 고쳐서 수직 오차를 맞추지 말 것.** 레벨의 `z` 를 고친다.
  레코드를 만지면 그 보정이 데이터에 남아 다른 소비자를 오염시킨다(과거 D6 사고).
- 층고는 레벨의 `height` 에 적는다. 레이어 높이를 이기고, 덮은 개수를 보고한다.

## 하지 말 것

- 층마다 임시 파이썬 스크립트 작성 (이게 없애려는 습관 그 자체다)
- 가드를 통과시키려고 `MIN_AXES`·`AMBIGUITY` 상수를 낮추기
- `--dry-run` 결과를 보여주지 않고 바로 조립
