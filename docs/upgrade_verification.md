## 이번 변경

원본 DXF의 곡선·블록 변환·단위·선택 영역을 프로젝트별 설비 프로파일에 연결했습니다. 배관과 덕트의 단면·높이는 Python/브라우저/빌더에서 같은 규약으로 처리합니다. GUI 설정, 수정 보존, source hash와 revision이 결합된 Codex 제안, Blender/GLB 내보내기와 검증을 추가했습니다. 기존 FreeCAD/IFC의 치수 덮어쓰기·외곽 압출·닫힌 경로·장비 높이 처리도 정리했습니다.

사용 방법은 [CODEX_WORKFLOW.ko.md](CODEX_WORKFLOW.ko.md), 기술 정리는 [modeling_techniques.md](modeling_techniques.md)에 있습니다. 소스 프로그램과 함께 `dist/MEP-Parser.exe`도 다시 빌드했습니다. 사용하지 않는 Qt 뷰어는 제외하고 Tk GUI를 유지했습니다.

## 실제 도면과 저장 3D 파일

최신 실무 난방 도면 실행은 원본 상단 배치 **271개 도형 → 5개 연속 경로**, 해석 길이 **351.952384985m**를 재현했습니다. **4.173788mm 원본 단절을 유지**했습니다. 실제 외경15.9와 바닥 구성은 이 예제의 가정이며 다른 현장의 기본값이 아닙니다.

최신 네이티브 실행: `outputs/sample-validation/<현장>_heating/blender/run_63c102c7dd3440519459ab3633812d05` (위 검증 작업 복사본 기준).
`model.blend`를 다시 열어 5개 편집 가능한 Curve와 실제 외경·높이·원본 참조·PB 재질/COIL 레이어/영역 메타데이터를 검사했고, `model.glb`의 실제 정점35,090개·활성 장면·Z70~85.9mm·메타데이터를 대조했습니다. 상위 `blender_build.json` 상태는 `verified`이며 파일 해시와 실행 ID를 포함합니다. 이 선택 프로파일에는 건축 slab가 없으므로 바닥과 건축을 임의 추가하지 않았습니다.

별도 범용 fixture에서는 다른 좌표·PB OD19·덕트237×83·구멍 있는 slab와 바닥층23/44/38을 네이티브 Blender로 검증했습니다. 단일 현장에 고정된 경로 생성기가 아닙니다.

**FreeCAD 최신 확장 fixture는 미실행**입니다. 4개 객체의 사전검사 오류0/경고0이지만 가용 RAM 약1.6GiB가 2GiB 기준에 미달했습니다. `outputs/sample-validation/freecad_contract/final_validation_status.json`에 `blocked_resource`로 기록했습니다. 앞선 2개 객체의 FCStd/IFC 저장·재열기·실제 외경/높이/구멍 체적 9개 검사는 통과했으나, 이 증거를 최종 4개 객체 또는 후속 코드 전체의 검증으로 확대하지 않습니다.

## 아직 필요한 검토

환기 명시 중심선 45개의 추출 연장은 원본과 일치합니다. 그러나 혼재 단면·말단·피팅·장비를 모두 자동 분류하는 기능은 완성 검증 대상이 아닙니다. 넓은 외곽선 규칙은 리브와 기호까지 면 후보로 만들 수 있습니다. 실제 환기 외곽선 시험은 원본5,152개 중 완전 반영2,425개, 미반영/부분 반영2,727개로 불완전성을 표시했습니다. 이를 완성 덕트 모델로 취급하지 않습니다.

현장별 레이어·색상·선종류·영역 및 실제 단면을 설정하고 Codex 제안과 원본 겹쳐보기를 이용해 검토합니다. 형상/교환 파일의 `verified` 상태는 열·수리·풍량·시공 설계 승인이 아닙니다.

## 설치 증거와 복원

검토된 파일 목록과 이전/이후 SHA-256은 작업 폴더의 `mep-parser-release-20260910/manifest.json`에 기록합니다. 설치 성공은 같은 폴더의 `installation_receipt.json`에 `installed_verified`로 기록되며, 이전 파일의 백업 위치도 포함합니다. 설치 대상 파일의 검토된 diff 및 개별 해시를 검사하고 교체 직전 다시 확인합니다. 검토 이후 변경된 파일은 덮어쓰지 않습니다. `.claude/settings.local.json`과 고객 레이어 맵(추적하지 않는 파일)은 덮어쓰지 않고 보존 해시를 확인합니다.

업그레이드 ZIP에는 변경 소스·설명서·스킬·프로젝트 MCP 설정과 새 EXE를 담습니다. 전체 저장소 복제본이나 원본 고객 DXF 배포본은 아닙니다. 위 실제 도면 검증 자료는 작업 복사본에 보존되어 있습니다.
