# 릴리스 전 수동 점검

자동 검사(`pytest tests` · `frontend` 의 `npm test`)가 덮지 **못하는** 것만 적는다. 브라우저·FreeCAD·
Pascal 편집 화면은 CI 에 없으므로 사람이 한 번 돌리고 결과를 여기 형식으로 적어 둔다.

자동으로 만들지 않는 이유: 화면 구동을 CI 에 넣으려면 브라우저와 FreeCAD 를 그 기계에 설치해야 하고,
그러면 게이트가 무거워져 아무도 안 돌린다. 대신 **순수 함수는 전부 node:test 로 잠갔다**
(`review_logic.js` — 행 HTML·배너·요청 본문·이스케이프). 여기 남은 것은 '붙는 자리' 확인이다.

## 5가지

| # | 확인할 것 | 통과 기준 |
|---|---|---|
| 1 | **이음 확정 · 취소 1회** — 미리보기 검토 목록에서 '이음 확정' → '확정 취소' | revision 이 +1, +1 되고 행이 '확정한 이음' ↔ '연결 후보' 로 오간다. 저장 표시가 '서버에 저장됨' |
| 2 | **일괄 확정 1회** — '일상 이음 후보 N건 일괄 확정' | revision 이 **한 번만** 오르고 결정 기록 한 건에 후보 id 가 N개. 확정한 수만큼 무리가 준다 |
| 3 | **Pascal 인스펙터 치수 1회** — 편집 화면에서 부재 치수를 바꾼다 | 저장 요청 1번 → revision +1, 그 뒤 메아리 저장은 `no_changes`(revision 그대로). 표시 revision 이 화면에서 바뀐다 |
| 4 | **(3b) 검토 목록 CSV** — GUI 버튼 | `<프로젝트>/review/clash_r<rev>.csv` · `connectivity_r<rev>.csv` 가 생기고 Excel 이 바로 연다(한글 안 깨짐) |
| 5 | **납품 검증 빌드 1회** — `(4) 납품 검증 빌드` | FCStd·IFC 둘 다 `verified`. `build.json` 의 `stage_seconds` 를 아래 표에 적는다(다음 사람이 소요를 안다) |
| 6 | **설비 도면 열기** — GUI `열기…` → 환기 평면도 | 종류 대화의 기본 선택이 '설비' · 확인하면 **설정 창**이 열린다(파싱하지 않는다) · 저장하면 브라우저까지 한 번에 · 검토 대기에 배경 기둥이 없다 |
| 7 | **건축 도면 열기** — GUI `열기…` → 건축 평면도 | 기본 선택이 '건축' · 확인하면 파싱 후 브라우저가 열린다(버튼 한 번) |

## 골든 등록 (새 실무 도면이 들어왔을 때)

도면은 고객 자료라 커밋하지 않는다. 다이제스트만 커밋한다.

1. `tests/golden.local.json`(gitignore)에 **중립적인 키**로 경로를 적는다 — 현장명·고객명 금지.
   - 레이어맵 파싱: `{"단위세대_난방": {"dxf": "...", "layer_map": "layer_map.csv"}}`
   - 설비 프로젝트: `{"단위세대_환기": {"project": "C:/.../unit.mep"}}`
2. `python tests/test_golden.py --bless` — **diff 를 읽고** 의도한 변화인지 확인한다.
3. 커밋 전 식별자 스캔 0건. 스테이징한 diff 와 **커밋 메시지 둘 다** `grep -nE` 로 본다. 파이프는
   `grep` 으로 끝내고 `head` 로 자르지 않는다 — 잘린 뒤의 한 건을 못 본다.

   **패턴을 이 문서에 적지 않는다.** 현장명·고객명을 적으면 그 자체가 유출이고, 나머지 토큰을 적으면
   스캔이 이 문서에 매번 걸려 진짜 한 건이 묻힌다. 각자 로컬에 두고 다음을 덮게 만든다:

   | 묶음 | 예 |
   |---|---|
   | 현장명·고객명·팀 이름 | 국문·영문 표기를 **둘 다** |
   | 로컬 경로 | 사용자 홈 아래 폴더명, 내려받기 폴더명 |
   | 자격증명 | API 키·토큰 접두사, 개인키 헤더, 클라우드 액세스 키 접두사 |
4. `tests/golden.json` 만 커밋한다(`golden.local.json` 은 gitignore 라 저절로 빠진다).
